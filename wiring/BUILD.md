This file orders the same ICs, parts and wires as `WIRING.md` into the bring-up phases of spec Section 11.1, so each phase can be built, powered and measured before the next one is added. Hole names follow the `WIRING.md` conventions.

## Checks on this sequence

- Every IC (43), part (298) and wire (669) of `WIRING.md` appears in exactly one phase; unassigned wires: 0.
- A wire is listed only once both of its end strips exist (an IC pin, a part lead, a rail, or a landing strip already reached by an earlier wire).
- For each phase the netlist is scanned for inputs whose driver is not fitted yet. They are listed as straps to add, and again as straps to remove in the phase that fits the driver. After the last phase none remain, which matches the ERC of `python3 -m sim check`.
- The 28C256 development-ROM variant below is a separate generated layout; it passes the same connectivity check and runs the diagnostic ROM in simulation (`tests/test_buildplan.py`).

**Check before the next phase**

- Scope MASTER_CLK at U5 pin 2 (BB1:e15): ≤600 kHz with clean Schmitt edges. Change the RC only with power off; the spec's 10 kΩ / 560 pF lands anywhere in 76–530 kHz (Section 5.3).
- Scope Q_A (U6 pin 5, BB1:e27), Q_B (U6 pin 9, BB1:f28) and Q_C (U45 pin 9, BB10:f31): the sequence 000→100→110→111→011→001 repeating, with no stray state (Section 5.5).
- PHI2 at the empty U1 pin 37 hole (BB1:g44): MASTER/6, ≤100 kHz, rise and fall ≤5 ns (Section 5.4). Use a ground spring on the probe.
- Power-up: COLD_CLEAR_N (U5 pin 6, BB1:e19) releases before CPU_RESET_N (U11 pin 8, BB3:f8) with at least two PHI2 cycles in between; expect roughly 30–150 ms. The CPU RESET button drops CPU_RESET_N only, never COLD_CLEAR_N.
- Reference waveform: `python3 -m sim run idle --vcd clock.vcd`, then view MASTER_CLK, Q_A, Q_B, Q_C, PHI2, COLD_CLEAR_N and CPU_RESET_N in GTKWave.

## Development ROM: 28C256 EEPROM in the U3 socket

The AT27C256R is one-time programmable, so every firmware iteration costs a chip. An AT28C256 EEPROM (pin-compatible with the AS6C62256 SRAM) fits the same socket with two pin changes: pin 1 becomes A14 instead of VPP, and pin 27 becomes /WE, held at +5 V, instead of A14. Its 150 ns access is far inside the read window at any legal clock. Program it with the same images; the TL866II Plus device list includes both AT27C256R and AT28C256. Return to the OTP part and the `WIRING.md` wiring for the qualified build. Wiring delta, generated from a second layout with U3 as a 28C256:

## Single-stepping the bus

MASTER_CLK leaves the oscillator on the jumper BB1:b15 → BB1:a25. To drive the board from a debounced manual or slow external clock, lift the BB1:b15 end and feed the clock into the BB1:a25 strip instead; the oscillator keeps running into nothing. Six master pulses make one CPU cycle, and the W65C02S is fully static, so the bus can be held and read at leisure. A bus monitor on A0–A15 (U1 pins 9–25) and C_D0–C_D7 (U1 pins 33–26) should sample on the falling edge of PHI2 at BB1:g44, where both read and write data are valid.
